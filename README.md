**Мой первый опыт в React и TypeScript.**

Я начал изучать React, чтобы создавать более сложные и динамичные приложения. В этом проекте я познакомился с компонентным подходом, использованием TypeScript для типизации и сборкой проекта через Vite. Это моя база для будущих более крупных проектов.

## Что было сделано
- Создание компонентов и их логическая связка
- Использование TypeScript для строгой типизации данных
- Настройка окружения с помощью Vite для быстрой работы

## Технологии
